Drawing flow

  1. Read the object and identify its longest, widest and highest faces.
  2. Draw light projection lines before adding the visible outline.
  3. Keep each view aligned. Transfer widths and heights between views.
  4. Add centre lines, hidden edges and dimensions with clear spacing.
